# Notebook Workflow

Use `src/run_analysis.py` as the reproducible analysis pipeline. For portfolio walkthroughs, create a notebook from the same sections:

1. Business problem and dataset overview
2. Data quality checks
3. Cleaning and feature engineering
4. KPI creation
5. Feature analysis and employee segmentation
6. Insights and HR recommendations

The script is preferred for GitHub because it can be run from a clean environment and regenerates every processed table, chart, and summary file.

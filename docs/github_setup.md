# GitHub Setup Guide

## Suggested Repository Name

`hr-analytics-employee-attrition`

## Suggested Description

End-to-end HR analytics portfolio project using Python, SQL, and Power BI to analyze employee attrition, retention KPIs, salary impact, overtime risk, job satisfaction, and employee segmentation.

## Setup Commands

```bash
git init
git add .
git commit -m "Create HR attrition analytics portfolio project"
git branch -M main
git remote add origin https://github.com/<your-username>/hr-analytics-employee-attrition.git
git push -u origin main
```

## Before Publishing

- Replace `<your-username>` in any GitHub links.
- Add dashboard screenshots after building the Power BI report.
- Do not commit `.venv/`, `.pbix`, or local cache files.
- Keep the raw dataset attribution in the README.
